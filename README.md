# ficheros-XML-Oracle

### Almacenamiento y validación de XML en Oracle

Este repositorio contiene los archivos desarrollados para el laboratorio de almacenamiento y validación de documentos XML en Oracle Database 21c.

## Contenido

- **`laboratorio.sql`**: consultas SQL y operaciones para generar, registrar, almacenar y validar documentos XML.
- **`empleados.xml`**: documento XML generado a partir de la información de empleados y departamentos.
- **`empleados.xsd`**: esquema que define la estructura y los elementos requeridos del documento XML.

## 🛠️ Herramientas utilizadas

- Oracle Database 21c XE.
- Oracle SQL Developer.


## Funcionalidades

- Consulta de las tablas EMPLOYEES y DEPARTMENTS.
- Generación de documentos XML mediante funciones SQL/XML.
- Registro de esquemas XSD en Oracle.
- Almacenamiento de documentos XML mediante XMLTYPE.
- Validación de documentos XML.
